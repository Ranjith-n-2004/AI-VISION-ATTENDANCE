# IMPORTANT INSTALL NOTES (Windows + GPU)
# 1) On Windows you must install a CUDA-enabled PyTorch wheel that matches your GPU drivers
#    before installing the rest of the packages. Visit https://pytorch.org/get-started/locally/
#    and choose the appropriate CUDA version for your system.
#
# Example PowerShell commands (change versions to match the recommended ones on pytorch.org):
# - CUDA 11.8 (common):
#   pip install "torch==2.2.0+cu118" "torchvision==0.16.0+cu118" --index-url https://download.pytorch.org/whl/cu118
# - CUDA 12.1 example:
#   pip install "torch==2.2.0+cu121" "torchvision==0.16.0+cu121" --index-url https://download.pytorch.org/whl/cu121
# - CPU-only (no CUDA):
#   pip install "torch==2.2.0+cpu" "torchvision==0.16.0+cpu" --index-url https://download.pytorch.org/whl/cpu
#
# After installing the appropriate torch/torchvision wheel, run:
#   pip install -r requirements.txt
#
# 2) dlib (required by `face_recognition`) can be difficult to build on Windows. Recommended options:
#   - Use conda/miniconda and install dlib from conda-forge, then pip install face_recognition:
#       conda create -n saas python=3.10 -y
#       conda activate saas
#       conda install -c conda-forge dlib cmake boost -y
#       pip install face_recognition
#   - Or find a prebuilt dlib wheel for your Python version and pip install it before installing face_recognition.
#
# 3) ultralytics (YOLOv8) uses torch and will use CUDA if torch is CUDA-enabled. Make sure torch is installed
#    correctly before installing ultralytics.
